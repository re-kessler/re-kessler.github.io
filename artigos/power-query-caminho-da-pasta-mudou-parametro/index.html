Power Query: o caminho da pasta mudou e a consulta quebrou

13 de novembro de 2026 · Renan Kessler

O relatório funcionava até alguém mover a pasta dos arquivos para outro disco. No primeiro Atualizar, a consulta parou com esta mensagem:

DataSource.NotFound: File or Folder: Não conseguimos encontrar a pasta 'C:\SiteTeste\FiliaisNovo\*'.

O texto é exatamente o que o Excel 365 devolveu no teste, apontando para uma pasta que não existe. O * no fim faz parte da mensagem. O Power Query monta esse padrão para listar o conteúdo da pasta, e ele aparece mesmo quando o caminho que você digitou não tem asterisco.

A correção óbvia é abrir o Editor Avançado e trocar o caminho no código. Funciona uma vez. O problema é que o caminho está escrito dentro de cada consulta que lê aquela pasta, e com três consultas são três edições, cada uma com a chance de uma aspa errada.

Guardar o caminho num parâmetro

Dentro do Editor do Power Query, abra Gerenciar Parâmetros na Página Inicial e escolha Novo Parâmetro. Dê o nome CaminhoPasta, marque o tipo Texto e escreva o endereço da pasta no campo Valor Atual, terminando com a barra invertida. Para os outros campos, valem as sugestões da própria janela.

Na lista de consultas, à esquerda, o parâmetro ganha um ícone diferente. O código dele cabe em uma linha. Esta é a que usei no teste:

"C:\Relatorios\Filiais\" meta [IsParameterQuery = true, Type = "Text", IsParameterQueryRequired = true]

Quem vale é o texto entre aspas. A parte depois de meta é metadado, que o Editor lê para exibir a consulta como parâmetro. Para o resto do código, CaminhoPasta é só um nome que devolve esse texto, e pode entrar em qualquer lugar onde hoje há um endereço digitado.

Usar o parâmetro na consulta

Numa consulta que lista os arquivos da pasta, o texto fixo sai e o nome do parâmetro entra:

let
    Arquivos = Folder.Files(CaminhoPasta),
    SoExcel = Table.SelectRows(Arquivos, each Text.Lower([Extension]) = ".xlsx"),
    Nomes = Table.SelectColumns(SoExcel, {"Name", "Folder Path"})
in
    Nomes

A consulta acima foi carregada numa planilha de teste e listou os arquivos da pasta pelo parâmetro. Outras consultas, como a que abre cada planilha, usam CaminhoPasta do mesmo jeito. O endereço passa a existir num lugar só.

Quando a pasta mudar

Abra o Editor, clique em CaminhoPasta no painel de consultas e troque o Valor Atual pelo endereço novo. Depois use Fechar e Carregar, ou Dados → Atualizar Tudo na planilha. Nenhuma linha de código muda, e quem cuida do relatório não precisa entender M para fazer isso.

A barra do fim merece uma nota. Com o parâmetro valendo C:\SiteTeste\Filiais, sem barra, Folder.Files listou os mesmos arquivos. A barra passa a ser obrigatória quando uma etapa cola o caminho a um nome de arquivo, como CaminhoPasta & "Filial_Sul.xlsx". O resultado, C:\SiteTeste\FiliaisFilial_Sul.xlsx, aponta para um arquivo que não existe. Escrever o valor sempre com a barra cobre os dois usos.

Onde isso quebra

O parâmetro guarda o texto que você digitou e não confere nada. Uma letra trocada em C:\Relatorios\Filias\ só aparece no momento da atualização, com a mesma mensagem DataSource.NotFound do início do artigo.

Essa mensagem tem uma serventia. O caminho que ela mostra, com o * no fim, é o que o Power Query tentou abrir de fato. Compare letra por letra com a pasta no Explorador de Arquivos antes de mexer em qualquer código.

O valor do parâmetro fica salvo dentro do arquivo do Excel. Um colega que receba o relatório e tenha os arquivos em outro disco continuará apontando para o seu endereço até trocar o parâmetro na máquina dele.
